# ALGO LAB — Design System & UI/UX Guidelines

## 1. Color Palette
- **Background Deep:** `#080D18` (Canvas main)
- **Background Surface / Card:** `#101A2B` (Panels, code editor, containers)
- **Background Elevate:** `#18253B` (Dropdowns, modals, hover states)
- **Borders & Dividers:** `#26364B`
- **Primary Brand Cyan:** `#22C5DD` (Buttons, highlights, active states)
- **Secondary Cyan:** `#16AFC6` (Hover, secondary CTAs)
- **Text Main:** `#F4F7FB` (Headings, primary content)
- **Text Secondary / Muted:** `#A5B2C5` (Descriptions, metadata)
- **Accent Derja Pedagogical Tag:** `#F59E0B` (Amber warmth for Tunisian Derja explanation cards)
- **Success Emerald:** `#10B981` (Passing test cases, correct answers)
- **Error Rose:** `#F43F5E` (Compiler errors, failed test cases)

## 2. Typography
- **Sans-serif:** Inter / system-ui for crisp French and Arabic/Derja clarity.
- **Monospace:** JetBrains Mono / Fira Code / Consolas for algorithmic notation and Python code.

## 3. Bilingual Pedagogical Card Pattern
Every concept is paired with:
1. **Définition Scientifique (Français):** Strict curricular accuracy, formal syntax.
2. **Explication Pédagogique (Derja Tunisienne):** Clear mental imagery, conversational tone, intuitive logic:
   - Example tag: `<span class="bg-amber-500/10 text-amber-400 border border-amber-500/20 px-2.5 py-1 rounded-full text-xs font-semibold">Tafsir b Tounsi</span>`
